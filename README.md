# Software Engineering & Computer Science Portfolio

A comprehensive repository containing my solutions, projects, and exercises across multiple programming languages and technologies. This serves as a personal knowledge base and a showcase of my software engineering practices.

## Technologies & Stack
- **Core Languages:** Python, Java, C, C++, Go, JavaScript, Bash, and more...
- **Databases:** PostgreSQL, MySQL, MariaDB, SQL Server
- **Tools:** Git, Docker, Neovim, JetBrains Suite

## Repository Structure
This repository is organized by technology. Each directory contains isolated projects, algorithms, and exercises.

- `/java` - Object-Oriented Programming and Design Patterns.
- `/cpp` - Data structures and memory management.
- `/python` - Scripting, algorithms, and data processing.
- `/sql` - Database normalization (1NF-5NF) and advanced relational queries.

## Branching Strategy (Gitflow)
This repository follows an industry-standard Gitflow workflow:
- `main`: Production-ready code and finalized projects.
- `develop`: Integration branch for ongoing work.
- `feat/*`: Feature branches for specific languages (e.g., `feat/java`).
